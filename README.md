# Моделирование столкновения бильярдных шаров

Проект моделирует абсолютно упругое столкновение двух гладких деформируемых шаров на плоскости. Контактная сила задаётся законом Герца

$$
F = k\delta^{3/2},
$$

а движение рассчитывается численным решением второго закона Ньютона. Для результата проверяются сохранение полного импульса и механической энергии, а конечные скорости сравниваются с аналитическим решением для упругого столкновения жёстких шаров.

## Установка

Требуется Python 3.13 или совместимая версия.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Без аргументов:

```bash
.venv/bin/python main.py
```

откроется окно для ввода параметров обоих шаров (масса, радиус, положение, скорость). После нажатия «Запустить» программа печатает максимальные отклонения импульса и энергии, затем открывает окно с анимацией столкновения и четырьмя графиками ошибок.

Тесты:

```bash
.venv/bin/python -m pytest -v
```

Список доступных сценариев:

```bash
.venv/bin/python main.py --list
```

Визуализация выбранного сценария:

```bash
.venv/bin/python main.py angled_equal_masses_second_at_rest
```

Скорость воспроизведения, замедление контакта и частоту кадров можно изменить:

```bash
.venv/bin/python main.py rear_end_equal_masses \
    --speed 2 \
    --slowdown 200 \
    --fps 30
```

## Структура проекта

```text
src/physics/state.py            состояние и создание шаров
src/physics/forces.py           контактная сила Герца
src/physics/dynamics.py         правая часть системы ОДУ
src/physics/integrator.py       численное интегрирование
src/physics/analysis.py         ЗСИ, ЗСЭ и аналитические скорости
src/physics/scenarios.py        сценарии для экспериментов
src/graphics/plotting.py        графики отклонений
src/graphics/visualization.py   совместная анимация и графики
src/graphics/setup_form.py      окно ручного ввода параметров шаров
src/scripts/                    вспомогательные скрипты для экспериментов
tests/                          численные и аналитические проверки
docs/                           отчёт и изображения
```

Все входные величины задаются в СИ: масса — в килограммах, длина — в метрах, время — в секундах, скорость — в метрах в секунду.
